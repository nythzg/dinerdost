## Design analysis

Current shell/navigation: restaurant Workspace and platform ConsoleShell have separate route/state/permission contracts. A later rollout should share visual primitives without merging authorization or navigation eligibility. Customer/storefront and sign-in flows need a lighter shell. Dense lists across orders, inventory, team and platform operations need one consistent toolbar, applied-filter chips, sorting and mobile row summaries. Complex floor editing must retain world coordinates, fixtures, snapping and interaction handles. Printed/issued documents are outside this visual restyling.

UI/UX Pro Max's design-system searches returned general minimalist/SaaS guidance but an unsuitable marketing hero pattern and replacement palettes. Only the applicable spacing, interaction, contrast and keyboard guidance is used; the supplied references and existing approved green theme govern this proposal. Gstack design-review principles inform visual inspection; its previously unavailable Bash runtime is not claimed to have run. The prototype is a visual spike explicitly requested by the user, not a completed ecosystem redesign.
